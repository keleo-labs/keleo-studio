================================================================================
                              KEY INSIGHTS
================================================================================

VALUE STREAMS:
  1. Service Boundary Stream:
     Define Boundaries → Draft API → Seed Team
                      → Publish API → Form Team
                      → Integrate API → Collaborate Team

  2. Cognitive Optimization Stream:
     Assess Load → Qualitative Assessment → Establish Principles
                → Quantified Assessment → Establish Foundation
                → Continuous Assessment → Work Well

PROGRESSION PATTERN:
  - Activities (1-time or recurring work)
  - Create/evolve Work Products (at increasing levels of detail)
  - Evidence Alpha States (progressive maturity)

VISUALIZATION BENEFITS:
  ✓ Shows HOW work creates value (not just WHAT states exist)
  ✓ Traces artifact lineage from source activities
  ✓ Identifies parallel vs. sequential work streams
  ✓ Reveals dependencies between activities and outcomes

INTERACTIVE FEATURES (in web UI):
  • Hover over nodes → See descriptions
  • Hover over flows → See connection details
  • Wider flows → More connections/relationships
  • Color coding → Quick category identification

================================================================================
                        ACCESS THE LIVE VISUALIZATION
================================================================================

1. Start the dev server:     npm run dev
2. Navigate to:              http://localhost:3000
3. Click:                    "Flow Visualizer" card
4. Select practice:          Choose from dropdown
5. Explore:                  Hover, zoom, pan

The live Sankey uses D3.js with smooth curves, automatic layout,
and interactive tooltips for a much richer experience than ASCII!
