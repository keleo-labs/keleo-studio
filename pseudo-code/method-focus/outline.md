Process for identifying a method or practice's focus. 

Create a section at the beginning of the view that identifies the primary focus of the method/practice. 

There are two parts to this section:
1. Primary focus - organised by focus show all alphas that have a score of more than zero, sorted by score
2. Not progressed by this method/practice - organised by focus, all alphas with a score of zero, sorted by order of appearance. 

To determine how to fill these sections, use the following process
1. Do not use baselinePractice elements in the scoring
2. Create a score property for each alpha
3. Increment the score based the following if provided by the method or practice:
   1. add 1 for each narrative 
   2. add 1 for each checklist (in the alpha's states)
   3. add 1 for each workproduct that contributes to the alpha (or its states)
   4. add 1 for each activity that contribes to the alpha (or its states)
   5. add 1 for each alpha that contributes to the alpha
